1. Principio de la solución

No se reemplaza el Inventario de Odoo. Se añade una capa sencilla para que el almacenero vea únicamente el trabajo que debe ejecutar.

Inventario nativo

Lo utiliza Logística y la administración para crear, planificar, corregir y auditar movimientos.

  • Recepciones y entregas.
  • Traslados internos.
  • Ubicaciones, reservas y trazabilidad.
  • Historial completo de movimientos.

Trabajo diario + Hanger

Lo utiliza el almacenero para ejecutar la operación asignada sin navegar por menús técnicos.

  • Por despachar.
  • Por recibir.
  • Listo para entregar.
  • Una acción principal por tarjeta.
Resultado: dos formas de ver la misma operación, sin duplicar documentos ni cantidades. Odoo mantiene el control; el Hanger simplifica la ejecución.

6. Reglas que no cambian

  • No se crean movimientos paralelos ni documentos duplicados.
  • Cada operador ve solamente los almacenes autorizados.
  • El conteo prepara cantidades; la validación sigue siendo una acción consciente.
  • Las diferencias físicas no se ocultan ni se corrigen automáticamente.
  • Todos los pasos conservan usuario, fecha, documento origen y chatter.
  • Las operaciones históricas deben conservar su respaldo documental.
Prueba local disponible: menú Operaciones → Almacén → Trabajo diario. La propuesta aún no modifica Gestión.
