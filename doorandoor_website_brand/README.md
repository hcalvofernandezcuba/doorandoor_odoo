# DoorAndDoor Website Brand

Módulo de identidad visual del website y portal de DoorAndDoor.

El logo provisional se encuentra en `static/src/img/doorandoor_logo.png`. Cuando
se reciba el manual corporativo deben sustituirse ese recurso, el favicon y las
variables visuales del archivo `website_brand.scss`, conservando las rutas para
no modificar las plantillas.

El alcance excluye deliberadamente el backend administrativo de Odoo.

## Paleta provisional

- Navy: `#0B1F33`
- Oro Suave: `#C9A96B`
- Gris Claro: `#D9D9D9`
- Blanco: `#FFFFFF`
