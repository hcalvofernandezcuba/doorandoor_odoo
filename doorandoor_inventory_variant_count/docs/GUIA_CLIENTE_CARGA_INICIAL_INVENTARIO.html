DOORANDDOOR

Guía de carga inicial de inventario

Selección guiada de productos y variantes en Odoo
Nueva función: se incorpora una entrada en español para encontrar productos por plantilla y seleccionar sus atributos, sin recorrer manualmente miles de variantes.
Conteos físicos → Sesiones de conteo → Agregar producto configurado

Versión funcional: 18.0.1.10.2
Documento para validación del cliente

1. Objetivo

Facilitar la carga inicial y el conteo de inventario. El operador selecciona primero el producto y luego Marca, Ancho, Alto, modelo, color, cristal, swing y los demás atributos aplicables. Odoo encuentra la variante exacta o crea una variante dinámica cuando la combinación todavía no existe.

Control: el asistente prepara el conteo, pero no modifica existencias inmediatamente. El inventario cambia únicamente cuando un responsable valida el ajuste.

2. Permisos necesarios

PerfilFunciones
Contador de inventarioCrear sesiones, seleccionar variantes, registrar cantidades y enviar a revisión.
Responsable de conteoTodas las funciones anteriores y validación final del ajuste.

Si no aparece el menú Conteos físicos, un administrador debe revisar los permisos del usuario y este debe volver a iniciar sesión.

3. Nueva entrada del menú

Después del despliegue aparecerá la nueva aplicación o entrada principal:

Conteos físicos

Sus opciones serán:

  • Sesiones de conteo: crear y validar cargas o conteos físicos.
  • Importar conteos de ítems: carga masiva mediante archivo.
  • Configuración → Ítems de conteo por variante: disponible para responsables.

4. Paso a paso: crear una sesión

Paso 1. Abra Conteos físicos → Sesiones de conteo.
Paso 2. Pulse Nuevo.
Paso 3. Seleccione la ubicación interna exacta donde se cargará o contará la mercancía.
Paso 4. Compruebe fecha, responsable y compañía; luego guarde.
Paso 5. Pulse Iniciar y cargar existencias.

Si la ubicación está vacía, la sesión puede comenzar sin líneas. Esto es normal durante una carga inicial.

5. Paso a paso: seleccionar el producto

Paso 1. En Captura por código de barras, pulse Agregar producto configurado.
Paso 2. En Producto, seleccione la plantilla: Impact Doors, Impact Windows, Interior Door u otra.
Paso 3. Seleccione exactamente un valor para cada atributo solicitado.
Paso 4. Revise el resumen y la Variante resultante.
Paso 5. Compruebe la ubicación y la Existencia actual.
Paso 6. Escriba la Cantidad contada, entendida como el total físico encontrado.
Paso 7. Mantenga Generar barcode marcado si la variante debe recibir un código para etiquetas y conteos posteriores.

Botones del asistente

BotónResultado
Agregar y continuarGuarda la variante en la sesión y abre un asistente nuevo para cargar el producto siguiente.
Agregar y cerrarGuarda la variante y regresa a la sesión de conteo.
CancelarCierra el asistente sin agregar el producto.
Importante: si una variante ya existe en la sesión sin lote, paquete o propietario, el sistema actualiza su cantidad contada y evita crear una línea duplicada.

6. Revisar y validar el inventario

  1. Abra la pestaña Variantes / Ajuste.
  2. Revise variante, existencia esperada, cantidad contada, diferencia y unidad.
  3. Compruebe lote, paquete y propietario cuando se utilice trazabilidad.
  4. Pulse Revisar.
  5. Si existe un error, pulse Volver al conteo y corríjalo.
  6. Un responsable pulsa Validar ajuste y confirma la advertencia.
Validar ajuste modifica el inventario real. Debe realizarse únicamente después de comprobar físicamente las cantidades.

7. Verificar e imprimir la etiqueta

  1. Abra Inventario → Productos → Productos.
  2. Abra la plantilla utilizada.
  3. Pulse Labels de productos.
  4. Seleccione Variantes.
  5. Localice la combinación agregada y revise atributos, referencia y barcode.
  6. Seleccione almacén, cantidad de copias y lote de impresión.
  7. Pulse Print y compruebe el PDF antes de imprimir.

El label individual debe identificar inequívocamente la combinación física. No debe utilizarse el label general de la plantilla para conteos de variantes.

8. Atributos dinámicos

Un atributo dinámico como swing no genera previamente decenas de miles de combinaciones vacías. Cuando el operador selecciona una combinación nueva, Odoo crea una variante real que puede tener stock, barcode, referencia y etiqueta propios.

9. Orden de validación y despliegue

  1. Local: validación técnica y funcional interna.
  2. Pruebas: validación del cliente con productos y ubicaciones de ensayo.
  3. Gestión: despliegue final después de aprobación escrita.

La disponibilidad en Pruebas o Gestión se comunicará expresamente después de cada despliegue. Este documento no autoriza por sí mismo cambios en producción.

10. Lista rápida de comprobación

  • La ubicación seleccionada es correcta.
  • Todos los atributos corresponden al producto físico.
  • La cantidad registrada es el total contado, no un incremento.
  • La variante tiene barcode si será etiquetada o escaneada.
  • Las diferencias fueron revisadas antes de validar.
  • El label muestra los atributos completos de la variante.
