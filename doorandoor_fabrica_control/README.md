# DoorAndDoor Fábrica Control

Módulo de control documental y operativo de la fábrica para Odoo 18 CE.

El diseño maestro se encuentra en
[`docs/DISENO_FUNCIONAL_FABRICA_Y_REPOSICION.md`](docs/DISENO_FUNCIONAL_FABRICA_Y_REPOSICION.md).

La revisión de los lanzadores existentes de venta, cobro, inventario y MRP se
encuentra en
[`docs/REVISION_FLUJOS_EXISTENTES.md`](docs/REVISION_FLUJOS_EXISTENTES.md).

La versión `18.0.1.0.0` contiene la estructura inicial instalable. Las fases
funcionales se incorporarán progresivamente y se validarán primero en local.
