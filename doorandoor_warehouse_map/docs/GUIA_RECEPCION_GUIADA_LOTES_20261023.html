Cómo usar el formulario

  1. Seleccione el Almacén de destino.
  2. Seleccione una recepción/traslado pendiente. Si no existe, deje el campo vacío: el sistema creará una recepción oficial de proveedor.
  3. Con un solo ITEM, se completa automáticamente. Con varios, solo aparecen los ITEM del documento.
  4. Indique la cantidad.
  5. Revise la propuesta: completa primero el lote del mismo ITEM si no supera 33 unidades. Si no cabe, propone el espacio vacío más cercano.

Protección: el modo queda bloqueado. El servidor rechaza convertir un traslado interno en una operación que genere labels.
